# 微信 ClawBot / iLink 通道

栖光庭可以把一张 Bot 卡的消息入口设为“微信 ClawBot / iLink”。保存后点击获取
二维码，用手机微信扫码并确认；确认得到的账号 Token 只保存在服务器私有密钥文件，
控制 API 和浏览器都不会再读回 Token 正文。

这条路线直接使用微信 ClawBot/iLink 通道，与腾讯 OpenClaw 微信插件使用同一类
账号入口，但不要求用户为了栖光庭再安装一套完整 OpenClaw。栖光庭仍负责选择
Codex、Claude Code、Grok 或 API 模型，并统一组装人物、外置记忆和 MCP 工具。

## 当前范围

- 支持多张微信 Bot 卡分别扫码、启停和运行。
- 支持微信私聊文字的接收与回复；可按空行或 `[SPLIT]` 分句，超长消息可独立开关自动拆分。
- 支持“正在输入”提示；每张 Bot 卡可单独关闭。
- 支持微信语音随消息携带的 `voice_item.text` 转写。微信未附转写时会明确提示，
  当前不把原始 SILK 音频伪装成已经识别。
- 支持表情图片和 TTS 音频文件发送。音频成功发送后默认只发文件，合成或发送失败时回退文字。
- 微信 Bot 暂未开放生图，生图预设和 `/draw` 在 Telegram 使用。
- 微信也使用一次性配对码和独立允许名单；扫码只连接 Bot 账号，不会自动授权所有来信人。
- 人物档案、聊天模型、思考档位、外置记忆与工具配置照常生效。
- 同步游标、最近消息 ID 和最近会话上下文保存在私有数据目录，重启后可接续。

## 能力核实表

| 能力 | 腾讯当前协议 / 官方插件 | 栖光庭当前状态 |
| --- | --- | --- |
| 私聊文字 | 已实现 | 已接入；需配对授权 |
| 分句与超长拆分 | 官方插件已有分块配置 | 已接入独立开关，默认开启 |
| 输入中提示 | `getConfig` + `sendTyping` | 已接入独立开关 |
| 用户语音转文字 | 语音项可能带 `voice_item.text`；官方插件也能下载并尝试解 SILK | 已接平台转写；原始 SILK 备用转写待后续依赖评估 |
| 图片 / 表情图片 | 官方 CDN 上传与图片消息 | 已接入；需要账号具备媒体上传权限 |
| Bot 语音回复 | 官方插件出站音频使用文件附件 | 音频文件，默认不重复发文字 |
| 收图理解 | 协议可收图片 | 未开放；当前聊天引擎契约仍是纯文字，不能假装看见图片 |
| 文件 / 视频理解 | 协议可收文件和视频 | 未开放；尚无安全的内容解析契约 |
| 群聊 | 当前 ClawBot 通道没有稳定的通用群聊承诺 | 未开放 |
| 主动唤醒 | 依赖最近一次 `context_token`，过期后可能投递失败 | 已开放固定或随机区间；失败不计每日成功额度，仍需真实账号验证有效窗口 |

协议依据来自腾讯公开的 [openclaw-weixin](https://github.com/Tencent/openclaw-weixin)：
README、`docs/protocol_zh_CN.md`、`src/messaging/inbound.ts`、`src/messaging/send.ts` 与
`src/cdn/upload.ts`。本仓库测试使用假微信响应验证请求形状，不会登录或调用真实账号。
图片与音频文件最终是否可投递仍受每个微信账号的服务端媒体权限影响，交接前保留一次
真实扫码烟测项，不把 HTTP 受理等同于手机已经收到。

## 与安卓桥的区别

安卓通知/无障碍桥适合没有可用 ClawBot/iLink 账号、又愿意准备专用安卓手机的部署。
它需要手机常驻、通知读取、无障碍发送、锁屏与保活处理，维护成本明显更高，因此不
作为公开通用版的默认入口。以后可以按同一渠道接口做成可选连接器，不需要改人物、
模型或记忆层。

扫码状态只在服务进程内短暂保存；服务重启或二维码过期后重新获取即可。解除微信
连接只删除该 Bot 的扫码账号凭据，不删除人物、模型、记忆连接或会话配置。

扫码授权与 Bot 启动是两个步骤。消息轮询成功后才显示已连接。若轮询时微信返回
`-14`，控制页会显示「会话已失效」。
重新获取二维码并在手机微信确认后，再查看 Bot 的运行状态。若手机明确提示「运行环境
存在风险」，该提示来自微信的授权页面。
