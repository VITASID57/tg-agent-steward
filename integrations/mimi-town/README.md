# 栖光庭 · 棉棉云小镇插件

1. 运行包含小镇导入接口的栖光庭版本。手机上请用能访问的 HTTPS 地址。还没有实例时，先看[部署说明](../../docs/deployment.md)。
2. 在小镇的插件中心选「添加插件 → 从文件安装」，导入 `lumenkeep.mimi-app.json`。
3. 打开插件，填栖光庭地址并同意连接。页面重新打开后，点「打开栖光庭」，在总览生成并复制「小镇导入口令」。
4. 回到插件填导入口令，点「连接」。看到「已连上」后，点「从小镇导入人设」，选居民并确认。
5. 点「打开人物档案」查看结果。在栖光庭的 Bot 设置里选择这份档案，保存后使用。

连接成功后，插件会记住地址和导入口令。点「忘记口令」可清除小镇保存的口令。口令撤销或更换后，插件发现旧口令失效时也会清除它。地址授权可以在小镇插件中心撤回。

小镇备份会带上导入口令，换设备恢复后不用重填；如果备份文件给了别人，请在栖光庭撤销或重新生成口令。

修改 `page.html` 后，在仓库根目录运行 `node integrations/mimi-town/build.mjs` 生成插件包。本插件沿用仓库的 [PolyForm Noncommercial 许可](../../LICENSE)。
