自动唤醒

随机区间会在每次检查后重新抽取下一次时间；安静时段内命中会重新抽签，不会每天固定在同一分钟冒头。

配对与 Telegram 行为

Telegram 支持私聊与群聊、外置语音转写、原生语音气泡、分句和短消息合并。下面每项都是发送行为开关，不会偷偷写进人物提示词。

微信入口使用扫码账号授权，支持私聊文字、微信自带语音转写、分句、输入中提示、生图、表情图片和音频文件回复；人物、记忆与 MCP 工具照常使用。

在微信里发送 /pair 配对码。原生语音气泡与群聊暂不开放；自动唤醒使用最近会话上下文并按实际投递结果记账。

VOICE ROUTES

声音预设

语气表现会自动工作

Bot 开启语音回复，并选择支持语气的首选线路后，模型会按当下语境少量使用耳语、轻声、叹气、笑声、紧张与停顿等表现。语气标记只交给念字服务，不显示在文字消息，也不写进记忆。

当前支持：ElevenLabs v4 / v4 Turbo / v3 与 Vertex / Gemini TTS；普通 Telegram 语音推荐高质量的 eleven_v4。其他线路仍可使用音色与自然标点，但会自动清理语气标记。
