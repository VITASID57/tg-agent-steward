管理密码是什么，在哪里设置？

它只保护这一份栖光庭。部署时可用 TG_STEWARD_ADMIN_PASSWORD 自己设置；每位部署者都有自己的，不来自 GitHub，也不是 Telegram Bot Token。

未设置时会自动生成并保存在部署数据目录的 .admin-token。只有服务仅供部署主机自己访问时，才能设置 TG_STEWARD_AUTH_MODE=none 免密码进入；可从网络访问的服务不允许关闭密码。

Telegram Bot Token 和模型 Key 请进入后台后分别填写。Windows 本地运行也可以双击项目中的 打开TG管家.cmd，自动启动并进入。
